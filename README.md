# Startup Name Generator

This Flutter application generates creative startup name suggestions by combining common English words. You can scroll through an infinite list of names, save your favorites, and view them later.

A new Flutter project.

## Getting Started

This project is a starting point for a Flutter application.

## Prerequisites
- Flutter SDK: [Installation Guide](https://flutter.dev/docs/get-started/install)

## Installation and Running
1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd startup_namer
   ```
3. Install dependencies (if any, though for this project `flutter run` usually handles it):
   ```bash
   flutter pub get
   ```
4. Run the application:
   ```bash
   flutter run
   ```

## Features
- Infinite scrolling list of startup name suggestions.
- Tap to save your favorite name combinations.
- View all saved suggestions on a separate screen.
- Utilizes the `english_words` package for generating word pairs.
